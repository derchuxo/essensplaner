Die App ist als installierbare PWA vorbereitet.
Standardmäßig sind 2 Personen eingestellt.

Auf dem iPhone:
1. Die App-Dateien über einen Webserver bereitstellen.
2. In Safari öffnen.
3. Teilen -> Zum Home-Bildschirm.

Hinweis: Ein lokales HTML kann geöffnet werden, aber für die vollständige PWA-Installation
muss sie über HTTPS bzw. einen Webserver ausgeliefert werden.
